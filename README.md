# DangasaBot
Bu loyiha ingilis tili va boshqa tilardagi so'zlarni yodalsh uchun ishlatiladigan Dangasona Bot hisoblanadi!


menga so'zlar lug'ati shaklangan ular essential 1dan 6gacha kitoblari mavjud va Navigate A1 da Navigate c1 gacha so'zlarni olib lug'at shaklantirish kerak esentia tayor turibdi 3600 ta so'z bor ekan 6ta kitobda, navigate endi shaklantirish kerak.

Bot bo'yicha:
1. Essential va Navigate kitob laridan tanalsh imkoniyati va uni ichidan unitlarni tanlash imkoniyati tanlangan unitlar bo'yicha quiz mode va write mode rejimlari bo'lishi kerak.
2. rasmga mos so'zlarni tanlash bunda ham sozlamalar bo'lishi kerak va u sozlamalarda write mode va quiz mode tanlashi kerak. vaqtni ham o'zi tanlashi kerak.
3. Translate game ingliz yoki o'zbek tili da gap beriladi shuni write mode ko'rinishida tarjima qilishi kerak foydalanuvchi.
qo'shimcha:
  1. Admin tomonidan mavzular qo'sha olishi va mavzlarga mos gaplar qo'shishi va bu gapni darajasini belgilashi yani A1, A2, B1, B2, C1 shunga o'xshash va unga oson, o'rtacha, va qiyint lik darajasini berish.

  2. Foydalanuvchi gaplarni yozib yuorganda avvalo 80% dan yuqoriligini ya'ni to'g'ri tarjima bilan solishtirish, keyin imloviy grammatik xatolarni tekshirishi kerak.

4. foydalanuvchini  so'zlar yodlanishini 1oylik natijalarini yig'ib boorish va ularni 1oyda qancha so'z yodlaganini,1haftada, 1kunda qancha so'z yodlaganini monitoring qilib borishi uchun ma'lumotlarini saqlab turish va 1oydaln keyin yanna 1oylik qancha so'z yodlagaligi haqida ma'lumotni saqlab yangi oydan boshidan boshashi kerak oylarni ham monitoring qilib borishi kerak. Va eng muhimi yodalaganlarini umumiy random tazrda test qilib boorish katta aniqlikda ishlashi talab etiladi.

5. botda web app bo'lishi kerak bu xudi platformadek bo'ladi. buni Ichida o'yinlar bo'ladi 1-oying:"So'z toppish harflar beriladi so'zlarga mos shulardan so'z topishi kerak bunda tarjimasi tepasida beriladi yani olma bunda a,p,l,e harflari beriladi shu orqali tezroq eslab qlishiga erishiladi foydalanuvchini. bu o'yin gruhlar bilan olib borilsa zo'r bo'ladi hamma o'z reytingini ko'roladi."; 2-o'yin:"Bu o'yinda 2ta eshik bo'ladi va tepada so'zni tarjimasi  beriladi buni ingilis tili yoki o'zbek tilidagisini topsih kerak agar topsa eshik ochiladi bo'lmasam yopiladi bunda vaqt qo'yilgan bo'ladi. Buni ham gruhlarda o'yin tarzida qo'yish kerak bo'ladi."
6. O'qituvchi uhun alohida bo'lim bo'ladi bundan o'qituvchi web app da khoot da test yaratganday test yaratadi va o'quvchilarga boshlashni bosa boshlaydi testlar sozlamalarini o'zi belgilaydi o'qituvchi uchun qulay bo'lishi kerak bo'ladi bunda. bunda o'qituvchi o'yin tashkilashtirsa ham bo'ladi eshik o'yinini savol bor tug'ri javob eshiklardan birida tanlab tanlab kiraveradi to marragacha va natijani hamma ko'rib turishi kerak va oxirida aytiladi kim birinchi o'rini olganini.
7. Adminga kunlik qancha odam foydalanayotganini statiskasini chiqarishi kerak bo'ladi.
